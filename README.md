# Alba Care Daily Checklist

Cloud-first iPhone/PWA daily checklist application for Alba Care Clinic.

## Included
- Supabase email/password authentication, password recovery and password change.
- Roles and per-user permissions.
- Admin user management and area assignment.
- 27 checklist areas / 614 checklist items seeded from the supplied Alba Care checklist PDF.
- Mobile checklist cards with only Item, C/NC/N/A, and Action Plan / Notes.
- Daily, 7-day and overall compliance dashboards with charts.
- CSV export and print/PDF reporting.
- Realtime in-app notifications.
- Optional admin email on checklist submission via Supabase Edge Function + Resend.
- PWA manifest/service worker for iPhone Home Screen installation.
