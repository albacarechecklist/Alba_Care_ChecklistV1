Alba Care Admin Checklist Management Update V2

Replace ONLY these files in your existing GitHub/local repository:
- app.js
- styles.css
- service-worker.js

Do NOT replace config.js. Your existing Supabase URL and publishable key remain unchanged.

New Admin features:
- Areas & Checklists tab
- Add/Edit clinic areas
- Reorder areas
- Activate/Deactivate areas
- Delete unused areas
- Add/Edit checklist items
- Reorder checklist items
- Activate/Deactivate checklist items
- Delete unused checklist items
- Historical data protection: used areas/items cannot be deleted; deactivate instead
- Active checklist item count is automatically synchronized

No new Supabase SQL is required with the existing Alba Care schema.
